# 問題

- s を wordDict内の文字で表現できるか
- すべて小文字なので文字の変換は不要
- wordDictはすべて異なる

# Step1

### 考えたこと

- 全探索しか思いつかない
- 順に前から文字を追って行って、wordDictに一致すれば続けて一致しなければFalseを返す
- 計算量は $O(10^6)$でぎりぎり間に合いそう

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        def word_check(start):
            if start == len(s):
                return True

            for end in range(start + 1, len(s) + 1):
                if s[start:end] not in wordDict:
                    continue
                if word_check(end):
                    return True
            return False
        
        return word_check(0)
```

TLE

- Start位置に異なるルートで到達しうるのでメモ化させるとよさそう

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        @lru_cache(None)

        def word_check(start):
            if start == len(s):
                return True

            for end in range(start + 1, len(s) + 1):
                if s[start:end] not in wordDict:
                    continue
                if word_check(end):
                    return True
            return False
        
        return word_check(0)
```

- 時間計算量： $O(N\times M \times L)$
- 空間計算量： $O(N)$

# Step2

### コードの修正

- s[start:end]は辞書側にはない文字数も作っていて効率が悪そう。
    - 辞書内の文字数についての情報を辞書でもっておいて、endの取る値を制限して無駄な値をとるようにしたい
- set()のほうが高速
    - `if s[start:end] not in wordDict` がリストだと $O(N)$
    - setだと $O(1)$

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        word_set = set(wordDict)
        lengths = set(len(word) for word in wordDict)

        @lru_cache(None)
        def word_check(start):
            if start == len(s):
                return True

            for l in lengths:
                end = start + l
                if end <= len(s) and s[start:end] in word_set:
                    if word_check(end):
                        return True

            return False
        
        return word_check(0)
```

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        queue = [0]
        visited = set()

        while queue:
            start = queue.pop(0)
            if start == len(s):
                return True
        
            if start in visited:
                continue
        
            for end in range(start + 1, len(s) + 1):
                if s[start:end] in words:
                    queue.append(end)
        
            visited.add(start)
        
        return False
```

- Trie木を用いたオートマトンの模倣
```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False

class Solution:
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        root = TrieNode()
        for word in wordDict:
            node = root
            for char in word:
                if char not in node.children:
                    node.children[char] = TrieNode()
                node = node.children[char]
            node.is_word = True

        queue = deque([0])
        visited = [False] * (len(s) + 1)
        visited[0] = True
        
        while queue:
            start = queue.popleft()

            if start == len(s):
                return True

            node = root
            for end in range(start, len(s)):
                char = s[end]

                if char not in node.children:
                    break
                
                node = node.children[char]

                if node.is_word:
                    next_index = end + 1
                    if not visited[next_index]:
                        visited[next_index] = True
                        queue.append(next_index)
                        
        return False
```
