# 問題

- 2つの配列
- 配列の要素の和を小さい順に並べる
- 前からk個を返す

# Step1

- 配列は小さい順に並べられている
- (0,0) から始まって、`nums1` か `nums2` のインデックスどちらかを1つずつ増やしていく
- かぶりが出る可能性があるので `visited=set()` で管理
- `heap` に和とインデックスを保存して和で並び替え
- `nums1` を１増やした場合と `nums2` を１増やした場合で比べて小さいほうを答えのリストにいれる

```python
import heapq

class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        if not (nums1 and nums2):
            return []

        visited = set()
        kth_min_set = []
        num_set = []

        heapq.heappush(num_set,(nums1[0] + nums2[0], 0, 0))        
        visited.add((0,0))

        while num_set and len(kth_min_set) < k:
            _, nums1_idx, nums2_idx = heapq.heappop(num_set)
            kth_min_set.append([nums1[nums1_idx], nums2[nums2_idx]])
            
            if nums1_idx + 1 < len(nums1) and (nums1_idx + 1, nums2_idx) not in visited:
                visited.add((nums1_idx + 1, nums2_idx))
                heapq.heappush(num_set, ((nums1[nums1_idx + 1] + nums2[nums2_idx]), nums1_idx + 1, nums2_idx))

            if nums2_idx + 1 < len(nums2) and (nums1_idx, nums2_idx + 1) not in visited:
                visited.add((nums1_idx, nums2_idx + 1))
                heapq.heappush(num_set, ((nums1[nums1_idx] + nums2[nums2_idx + 1]), nums1_idx, nums2_idx + 1))

        return kth_min_set
```

- 時間計算量： $O(k\log k)$
- 空間計算量： $O(k)$

# Step 2

- 初めに `nums1` の各要素と `nums2[0]` のペアをすべてヒープにいれる
- `visited` を使わずに済む

```python
import heapq

class Solution:
    def kSmallestPairs(self, nums1: List[int], nums2: List[int], k: int) -> List[List[int]]:
        if not nums1 or not nums2:
            return []
        
        kth_min = []
        num_set = []
        
        for i in range(min(len(nums1), k)):
            heapq.heappush(num_set, (nums1[i] + nums2[0], i, 0))

        while num_set and len(kth_min) < k:
            _, idx1, idx2 = heapq.heappop(num_set)
            kth_min.append([nums1[idx1], nums2[idx2]])
            
            if idx2 + 1 < len(nums2):
                heapq.heappush(num_set, (nums1[idx1] + nums2[idx2 + 1], idx1, idx2 + 1))
                
        return kth_min
```

- 空間計算量： $O(\min(n, k))$
    - heap のみ
