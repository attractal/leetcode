# Step1

- **DP**
    - **状態の定義：** `dp[i]` = `i` 番目の要素を末尾とする、最長増加部分列の長さ
    - **漸化式の導出：**
        - 過去の数字 `nums[j]` よりも、今の数字 `nums[i]` の方が大きければ、過去の数列の後ろに今の数字をくっつけることができる
        - **条件:** `nums[i] > nums[j]`
        - **漸化式:** `dp[i] = max(dp[i], dp[j] + 1)`
    - **初期条件の決定：**
        - `dp[i]` = 1

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        dp = [1] * n
        
        for i in range(1, n):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)
                    
        return max(dp)
```

- 時間計算量： $O(n^2)$
- 空間計算量： $O(n)$

## Step 2

- `dp` だとわかりにくそう
    - `subsequences` に変更
- `i` ,`j` もわかりにくそう
    - `current_idx` と `previous_idx`

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        subsequences = [1] * n
        
        for current_idx in range(1, n):
            for previous_idx in range(current_idx):
                if nums[current_idx] > nums[previous_idx]:
                    subsequences[current_idx] = max(subsequences[current_idx], subsequences[previous_idx] + 1)
                    
        return max(subsequences)
```

### Follow Up
- 新しい配列 `sub`を用意
    - `sub[i]` = 長さ `i+1` の増加部分列を作るとき、その末尾になる数字のうち一番小さい数字
- **`x` が `sub` の最後の数字より大きい場合：**
    - `sub` の末尾に `x` をそのまま追加
- **`x` が `sub` の最後の数字以下の場合：**
    - `sub` の中から `x` 以上である最初の数字 を探し、それを `x` で上書き

```python
from bisect import bisect_left

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        # 増加部分列の「最小の末尾」を管理する配列
        sub = []
        
        for x in nums:
            # sub の中で x 以上となる最初の要素のインデックスを二分探索で探す
            # 例: sub=[2, 5, 8], x=4 の場合、5の場所(インデックス1)が返る
            idx = bisect_left(sub, x)
            
            # もし idx が sub の長さと同じなら、x は sub のどの要素よりも大きいということ
            if idx == len(sub):
                sub.append(x) # 記録更新（列を伸ばす）
            else:
                # より小さな値で末尾を上書きし、今後の増加の可能性を広げる
                sub[idx] = x
                
        # 最終的な sub の「長さ」が、最長増加部分列の長さになる
        return len(sub)
```
