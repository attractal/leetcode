# 問題

- `nums1` と `nums2` の積集合をとる
- 制約
    - どちらも要素を少なくとも1つは持つ

# Step 1

- 積集合をとればよい

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1_set = set(nums1)
        nums2_set = set(nums2)
        intersection = []
        for num in nums2_set:
            if num in nums1_set:
                intersection.append(num)

        return intersection
```

- 時間計算量： $O(N+M)$
- 空間計算量： $O(N+M)$

```python
from collections import Counter

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1_to_count = Counter(nums1)
        intersections = []
        
        for num in nums2:
            if nums1_to_count.get(num, 0) > 0:
                intersections.append(num)
                nums1_to_count[num] = 0 
                
        return intersections
```

- 空間計算量： $O(min(M,N))$

```python
from collections import Counter

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        def search_intersection(small, large):
            intersections = []
            num_to_count = Counter(large)
            for num in small:
                if num_to_count.get(num, 0) > 0:
                    intersections.append(num)
                    num_to_count[num] = 0
            return intersections
        
        if len(nums1) > len(nums2):
            return(search_intersection(nums2, nums1))
        else:
            return(search_intersection(nums1, nums2))
```

- `nums1` `nums2` がソート済みならマージソートのような Two-pointers で実装がはやそう

```python
class Solution:
    def intersection(self, nums1, nums2):
        nums1.sort()
        nums2.sort()
        
        ptr1 = 0
        ptr2 = 0
        intersection = []
        
        while ptr1 < len(nums1) and ptr2 < len(nums2):
            if nums1[ptr1] == nums2[ptr2]:
                intersection.append(nums1[ptr1])
                ptr1 += 1
                ptr2 += 1
            elif nums1[ptr1] < nums2[ptr2]:
                ptr1 += 1
            else:
                ptr2 += 1
        
        return list(set(intersection))
```
