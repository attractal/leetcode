# 問題

- ソートされたリストが渡されたときそれをうまく配置して左右の深さが1以下の平衡木を作る

# Step1

- １本のビーズ付きの飾りをバランスがとれるように飾り付けるなら、真ん中を固定するしかない
- 何か所も固定するなら真ん中できった中で真ん中のビーズ
- 同じ問題の繰り返しで上で判定する必要もないから、トップダウン形式で
- 伝えないといけないものは、揃えてほしい配列くらい

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        mid = len(nums) // 2
        root = TreeNode(nums[mid])

        root.left = self.sortedArrayToBST(nums[:mid])
        root.right = self.sortedArrayToBST(nums[mid + 1:])

        return root
```

としたが[1,3]の入力でうまくいかず。問題は `mid = (left + right) // 2` でrootをつくったときのmidとずれてしまう。最初の中央値の代入もループないで行うようにすれば解決！

```python
class Solution:
    def sortedArrayToBST(self, nums):
        if not nums:
            return None

        queue = deque()
        root = TreeNode(0)

        queue.append((root, 0, len(nums) - 1))

        while queue:
            node, left, right = queue.popleft()

            mid = (left + right) // 2
            node.val = nums[mid]

            if left <= mid - 1:
                node.left = TreeNode(0)
                queue.append((node.left, left, mid - 1))

            if mid + 1 <= right:
                node.right = TreeNode(0)
                queue.append((node.right, mid + 1, right))

        return root
```
