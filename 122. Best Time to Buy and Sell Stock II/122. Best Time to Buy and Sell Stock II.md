# 問題

- 持てる株は1つだが何度もやり取りできる
- そのときの最大利益
- price は常に正で長さは1以上

# Step 1

- 今の最適解が過去に依存しているという点でDPが最適そう
- 持っている状態と持っていない状態がこまめに切り替わりそうなので貰うDPで2つの状態を管理する
- 何も持っていない状態と株を持っている状態の2つを管理
- 何も持っていない状態になる：
    - 漸化式：  $max(何も持たない,  株を持っている状態から売る)$
- 持っている状態になる：
    - 漸化式： $max(持っていて売らない, 持っていなくて買う)$
- 初期値：何も持っていないときは0
- 初期値：持っている状態のときは高い株を買ったとき

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        before_buy = 0          # 何も持ってない状態
        holding = float('-inf') # 株を持ってる状態

        for price in prices:
            new_before_buy = max(before_buy, holding + price)  # 何もしない or 売る
            new_holding = max(holding, before_buy - price)     # 何もしない or 買う

            before_buy = new_before_buy
            holding = new_holding

        return before_buy
```

- 時間計算量： $O(N)$
- 空間計算量： $O(1)$

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        profit = 0
        buy = float('inf')
        
        for price in prices:
            if buy > price:
                buy = price
                continue
            if price > buy:
                profit += (price - buy)
                buy = price

        return profit
