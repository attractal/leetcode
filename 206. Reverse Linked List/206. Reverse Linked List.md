# Step1

1. **反復 1**
    - stack で解けそう
        - 連結リストの `node.val` を格納したリストを作成
        - 後ろから取り出し新たなリストにつなげる
        - 後ろの操作なので `deque` と変わらないと考え `list` を採用
    - `dummy` を用意し `head` を固定
    
    ```python
    # Definition for singly-linked list.
    # class ListNode:
    #     def __init__(self, val=0, next=None):
    #         self.val = val
    #         self.next = next
    class Solution:
        def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
            
            node = head
            numbers = []
    
            while node is not None:
                numbers.append(node.val)
                node = node.next
    
            dummy = ListNode()
            ans = dummy
    
            while numbers:
                val = numbers.pop()
                dummy.next = ListNode(val)
                dummy = dummy.next
    
            return ans.next
    ```
    
    - 時間計算量： $O(n)$
    - 空間計算量： $O(n)$
2. **反復 2**
    - `ListNode` の繋ぎ変えで空間計算量を $O(1)$にできそう
    - 左から矢印の向きを逆転させる
    
    ```python
    class Solution:
        def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
            previous = None # ノードの1つ前を指す
            node = head
            
            while node is not None:
                next_node = node.next  # 次のノードを一時保存
                node.next = previous   # 現在の向きを逆にする
                previous = node        # 前のノードを移動
                node = next_node       # 現在のノードを移動
                
            return previous
    ```
    
3. **再帰**
- ベースケース：空リスト、または要素が1つだけならそのまま返す
- 再帰的に今のノードより先をすべて逆転させる
    - new_head は、元のリストの末尾（新しい先頭）がずっと保持される
- 矢印をひっくり返す
    - head.next（次のノード）の .next を 自分自身（head）に向ける
- 元の向きの矢印を断ち切る（Noneにする）

```python
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
   
        if head is None or head.next is None:
            return head

        new_head = self.reverseList(head.next)

        head.next.next = head

        head.next = None

        return new_head
```
