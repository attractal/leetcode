# 問題

- 二分探索を素直に実装

# Step 1

- `left` と `right` の2つのポインタで中央の `mid` と `target` の値を比べてポインタを更新する

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        if not nums:
	          return 0
        
        left = 0
        right = len(nums) - 1

        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid
            
            elif nums[mid] > target:
                right = mid - 1
            
            else:
                left = mid + 1

        return left
```

### 二分探索まとめ

- 値が入る場所を探す,完全一致を探す
    - `right` の初期値：
        - `length - 1` ： 閉区間 [left, right]
            - 両端を含む
            - ループ条件は `while left <= right`
            - `left` と `right` が同じ場所を指しているときもチェックが必要
            - 閉区間なのでその値自身が範囲に入るため
        - `length` ： 半開区間 [left, right)
            - `left` から `right` の1つ手前まで探す
            - ループの条件は `while left < right`
            - `left`  と `right` が重なった時点で探索範囲が空になるため
    - 2で割る処理
        - 無限ループをどう防ぐか
        - 切り捨て：
            - 次を探索するときに `left = mid + 1` や `right = mid - 1` と更新する場合
        - 切り上げ：
            - `left = mid` と更新する場合
            - `left = 0` 、 `right = 1` でバグる
- 境界探し
    - [1, 2, 3, 3, 5] で target = 3 で一番最後の 3 を見つけたいとか
    - 上限
    
    ```python
    while left <= right:
        mid = (left + right) // 2
    
        if nums[mid] <= target:
            # ターゲットと同じ値であっても、
            # もっと右に同じ値があるかもしれないと考えて、範囲を右側に絞る。
            left = mid + 1
        else:
            right = mid - 1
    
    # left  -> targetより大きい最初の要素を指す
    # right -> targetの最後の出現位置を指す
    ```
    
    - 下限
    - 今の値がターゲットと同じか大きいなら、探している境界線はここか、あるいはもっと左にあるはず
 
    ```python
    # ターゲット以上の条件をまとめる
    if nums[mid] >= target:
        right = mid - 1  # ターゲットを見つけても、さらに左に同じ値があるかもしれないから左を探し続ける
    else:
        left = mid + 1
    ```
