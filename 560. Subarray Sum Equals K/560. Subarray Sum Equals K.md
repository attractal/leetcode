# 問題

- 数列 `nums` 、数字 `k` が与えられている
- 累積和がkとなる組み合わせの数を返す
- 制約
    - 数列は負の値をとりうる

# Step 1

- アルゴリズムの選択
    - 部分和なので累積和を使うと効率よくできそう
    - 累積和がターゲットの値になるとき、累積和を格納したリストの中の要素の差分がターゲットの値になるときにカウントを増やす
    - 累積和のリストをつくったらTwo-Sum的解き方ができそう

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
    
        prefix = [nums[0]] * len(nums)
        count = 0
        
        for i in range(1,len(nums)):
            prefix[i] = prefix[i - 1] + nums[i]
            
        prefix_to_count = {0 : 1}
        
        for num in prefix:
            complement = num - k
            if complement in prefix_to_count:
                count += prefix_to_count[complement]
            prefix_to_count[num] = prefix_to_count.get(num, 0) + 1

        return count     
```

注) `prefix_to_count` をはじめに `0:1` で初期化するのは、先頭(インデックス0)から始まる部分配列の和が `k` になるケースも正しくカウントするため

- 時間計算量： $O(N)$
- 空間計算量： $O(N)$

# Step2

### コードの修正

- prefix を作るのは非効率そう
- はじめから `prefix_to_count` を作ればよさそう

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        prefix_to_count = {0 : 1}
        count = 0
        prefix = 0
        
        for num in nums:
            prefix += num
            complement = prefix - k

            if complement in prefix_to_count:
                count += prefix_to_count[complement]

            prefix_to_count[prefix] = prefix_to_count.get(prefix, 0) + 1

        return count 
```

- complement はあまりよくない命名かも
```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        prefix_to_count = defaultdict(int)
        prefix_to_count[0] = 1  
        
        count = 0
        prefix = 0
        
        for num in nums:
            prefix += num
            
            target_prefix = prefix - k
            
            if target_prefix in prefix_to_count:
                count += prefix_to_count[target_prefix]

            prefix_to_count[prefix] += 1

        return count
```
