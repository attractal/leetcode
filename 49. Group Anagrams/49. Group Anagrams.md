# 問題

- 文字の構成するアルファベットが同じものをまとめて配列にして返す
- 制約
    - 空リストあり
    - anagram 内では順不同
    - anagram の種類の順番も順不同
    - すべて小文字

# Step1

- anagramの代表値をキー、配列ででてきたものを値にもつ辞書型を作る
    - 値に複数入る、動的であることから `defalutdict` を採用
- 最初に書いたコードは以下、ただし動かず

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = defaultdict(list)

        for word in strs:
            word_sort = "".join(sorted(word))
            
            if word_sort not in anagrams:
                anagrams[word_sort] = word
            
            else:
                anagrams[word_sort].append(word)

        return list(anagrams.values())
```

- `anagrams[word_sort] = word` で代入を str 型にしてしまっているため `append` メソッドがないというもの
- そもそもこの条件分岐が不要なので
    - 存在しないキーにアクセスした瞬間、自動的に空のリスト `[]` を作成してくれるのが `defaultdict`

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = defaultdict(list)

        for word in strs:
            word_sort = "".join(sorted(word))
            anagrams[word_sort].append(word)

        return list(anagrams.values())
```

https://docs.python.org/ja/3/library/collections.html#collections.defaultdict

- 時間計算量： $O(N\times K\log K)$
    - 配列走査に $O(N)$、代表値探しのソートに $O(K\log K)$
    - 今回は N >> K なのでほぼ $O(N)$
- 空間計算量： $O(N\times K)$

# Step 2

### コードの修正

- `dict` でも配列を値にもてるので、 `append` が可能と気づいた
- `defaultdict` との違いはキーが新規である場合にエラーを起こすか、Noneを返すかの違いそう

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = {}

        for word in strs:
            word_sort = "".join(sorted(word))
            
            if word_sort not in anagrams:
                anagrams[word_sort] = [word]
            else:
                anagrams[word_sort].append(word)

        return list(anagrams.values())
```

- `get()` を用いてよりスマートに

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = {}

        for word in strs:
            word_sort = "".join(sorted(word))
            current_list = anagrams.get(word_sort, [])
            current_list.append(word)
            anagrams[word_sort] = current_list

        return list(anagrams.values())
```

- `setdefault` というメソッドもありそう
    - https://docs.python.org/ja/3/library/stdtypes.html#dict.setdefault

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        anagrams = {}

        for word in strs:
            word_sort = "".join(sorted(word))
            anagrams.setdefault(word_sort, []).append(word)

        return list(anagrams.values())
```

- `get()` との違い、辞書を書き換えられる
