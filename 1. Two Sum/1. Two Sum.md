# 問題

- 整数の配列とターゲットとなる数字が与えられたとき、足してターゲットの数字になる2つの要素のインデックスを返す
- 制約
    - 答えは必ず1セット存在すると仮定して良い
    - 同じ要素を2回使ってはいけない
    - 答えを返す順番は問わない

# Step 1

- 愚直に全探索で $O(N^2)$
- Hash を使って数字とインデックスを保存していけば、配列を1回走査するだけ
    - 今見ている値と、目標値からそれを引いた値を今までにみたか
        - 見たならそのインデックスを返す
        - 見ていなければ待ちリストに値とインデックスを保存

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
       
        visited = {}
        idx = 0
        pair = []
        
        for i in range(len(nums)):

            if target - nums[i] not in visited:
                visited[nums[i]] = i
                continue
            
            if target - nums[i] in visited:
                pair.append(visited[target - nums[i]])
                pair.append(i)
                return pair
        
        return None

```

- 時間計算量： $O(N)$
- 空間計算量： $O(N)$

# Step 2

#### コードの修正

- `target - nums[i]` を毎回計算しなくてはならない
    - 可読性低い
    - 新しい変数で置く
- インデックスと要素を同時に取得したほうがわかりやすい
    - `enumerate` 関数で一括管理
    - https://docs.python.org/ja/3/library/functions.html#enumerate
        - index が先に来ることに注意
- `pair` に `append` しないで直接返す
- `idx` 使っていないのに初期化している

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
       
        visited = {}
        
        for i, num in enumerate(nums):

            complement = target - num

            if complement not in visited:
                visited[num] = i
            
            else:
                return [i, visited[complement]]
        
        return None

```
