# 問題

- i日目の株価の配列である`prices` が与えられる
- いつ買っていつ売れば収益を最大化できるか
- 取引は1回までできる
- 最小0

# Step1

- 全探索で $O(N^2)$
- ある時点の最適な状態が過去に由来するという構造からDPがよさそう
- 状態：dp[i] で i日目までの最大収益
- 漸化式：dp[i] = max(dp[i-1], sell - buy)
- buy = min(buy, prices[i])
    - 安くなった時に買うの方針
- 初期値：dp[0] = 0
- 初期値：初日の株は購入済みに設定

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        profit = 0
        buy = prices[0]

        for price in prices:
            if price < buy:
                buy = price
            profit = max(profit, price - buy)

        return profit
```

- 時間計算量： $O(N)$
- 空間計算量： $O(1)$

            for price in prices:
                new_before_buy = before_buy
                new_holding = max(holding, before_buy - price)

```python
class Solution:
    def maxProfit(self, prices):
        if not prices:
            return 0
            
        buy = float('inf')
        profit = 0

        for price in prices:
            if price < buy:
                buy = price
            profit = max(profit, price - buy)

        return profit
```
