# 問題

- 62の問題に加えて障害物ができた時のパスの総数
- マス目が1でそこに障害物がある場合は例外処理が必要そう

# Step1

- アルゴリズムの選択

動的計画法

- 状態：そのマス目に来るまでの行き方の総数
- 漸化式：
    - `dp[i][j] = dp[i-1][j] + dp[i][j-1]` (grid[i][j]≠1)
    - `dp[i][j] = 0`
        
        (grid[i][j] == 1)
        
- 初期値：
    - スタート地点が1

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        if not obstacleGrid or obstacleGrid[0][0] == 1:
            return 0

        num_rows = len(obstacleGrid)
        num_cols = len(obstacleGrid[0])
        patterns = [0] * num_cols
        patterns[0] = 1

        for row in range(num_rows):
            for col in range(num_cols):
                if obstacleGrid[row][col] == 1:
                    patterns[col] = 0
                    continue
                if col >= 1:
                    patterns[col] += patterns[col - 1]
        
        return patterns[-1]
```

- 時間計算量： $O(N\times M)$
- 空間計算量： $O(M)$

```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        OBSTACLE = 1

        if not obstacleGrid or not obstacleGrid[0]:
            raise ValueError("The grid must not be empty.")
            
        num_rows = len(obstacleGrid)
        num_cols = len(obstacleGrid[0])

        if obstacleGrid[0][0] == OBSTACLE:
            return 0
        if obstacleGrid[num_rows - 1][num_cols - 1] == OBSTACLE:
            return 0

        patterns = [0] * num_cols
        patterns[0] = 1 

        for row in range(num_rows):
            for col in range(num_cols):
                if obstacleGrid[row][col] == OBSTACLE:
                    patterns[col] = 0
                elif col > 0:
                    patterns[col] += patterns[col - 1]
        
        return patterns[-1]
```
