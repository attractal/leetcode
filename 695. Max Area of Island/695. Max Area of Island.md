# Step1

## DFS

- **ベースケース:** 範囲外、訪問済み、または海（`0`）の場合は `0` を返して終了。
- **再帰の仕組み:** `1 + 四方向の探索結果` として、つながっている島を足し合わせる

```python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        visited = set()
        area = 0
        max_area = 0

        def countArea(r,c):
            if r not in range(rows) or c not in range(cols) or (r,c) in visited or grid[r][c]==0:
                return 0
            visited.add((r,c))
            area = 1 + countArea(r-1,c) + countArea(r+1,c) + countArea(r,c-1) + countArea(r,c+1)
            return area
        
        for r in range(rows):
            for c in range(cols):
                max_area = max(max_area,countArea(r,c))
        
        return max_area
```

- **計算量**
    - 時間計算量： $O(H \times W)$
    - 空間計算量： $O(H \times W)$

## BFS

- **起点:** 陸地（`1`）を見つけたら、そこをキュー（待ち行列）に入れる。
- **探索:** キューから1つ取り出し、その「上下左右」の隣人を確認する。
- **拡張:** 隣が未訪問の陸地なら、キューに追加して「訪問済み」にする。
- **反復:** キューが空になるまで（＝地続きの陸地がなくなるまで）繰り返す。

```python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        if not grid: return 0
        rows, cols = len(grid), len(grid[0])
        visited = set()
        max_area = 0

        def bfs(r, c):
            queue = deque([(r, c)])
            visited.add((r, c))
            area = 1
            
            while queue:
                curr_r, curr_c = queue.popleft()
                for dr, dc in [(1,0), (-1,0), (0,1), (0,-1)]:
                    nr, nc = curr_r + dr, curr_c + dc
                    if (0 <= nr < rows and 0 <= nc < cols and 
                        grid[nr][nc] == 1 and (nr, nc) not in visited):
                        visited.add((nr, nc))
                        queue.append((nr, nc))
                        area += 1
            return area

        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1 and (r, c) not in visited:
                    max_area = max(max_area, bfs(r, c))
        
        return max_area
```

- **計算量**
    - 時間計算量： $O(H \times W)$
    - 空間計算量： $O(H \times W)$
