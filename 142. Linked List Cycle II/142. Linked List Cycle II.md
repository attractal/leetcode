# Step1

141 と同様に, 訪問した node を set() に格納し, 一致すればそれを返すことで計算量 O(n) で実現.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        visited = set()
        node = head
        while node is not None:
            if node in visited:
                return node
            visited.add(node)
            node = node.next
        return None
```

- 時間計算量：O(n)
- 空間計算量：O(n)

空間計算量を O(1) にする方法について考える.

これは Floyd の方法の拡張で実現可能。

1. slow と fast を動かし, ループがある場合どこかで出会う
2. fast を head に動かし, どちらも一歩ずつ動かすと, ループのはじまりで出会うことが可能

連結リストの出発点からループ開始時点までを x とし, 出会った地点からループ開始点までを y とする.

ループ一周分を a とした場合, 

$a - x + y = a$

であるから, 

$x = y$

と導ける. 

※ slow と fast の距離の差はループ一周分であることに注意

つまり, 片方を先頭に, もう片方を出会った地点に据え, 同じ速度で進むことで, 距離が同じであるため必ずループ開始地点で会うことができる. 

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        fast = head
        slow = head
        while fast and fast.next is not None:
            fast = fast.next.next
            slow = slow.next
            if fast is slow:
                meet = slow
                fast = head
                while fast is not None:
                    if fast is slow:
                        return slow
                    fast = fast.next
                    slow = slow.next
```

より

- 時間計算量：O(n)
- 空間計算量：O(1)

で実現可能に.

# Step2

1. ネストが深いこと
2. fast, slow のポインタの使いまわしによる可読性の低下

以上2点が問題に感じられた.

まず 1 について,

- https://github.com/go-toh/LeetCode_Arai60/pull/2/commits/6c7e5520dd1043a331732df61347360da266c40a
    - meet を探す操作と ループ開始地点を探す操作で分かれていてネストが深くない
    - ただ, slow と fast を使いまわしていた

次に2について, 上記コードを参考に書きなおした.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        fast = head
        slow = head
        meet = None

        while fast is not None and fast.next is not None:
            fast = fast.next.next
            slow = slow.next
            if fast is slow:
                meet = slow
                break

        if meet is None:
            return None

        pointer1 = meet
        pointer2 = head
        while pointer1 is not pointer2:
            pointer1 = pointer1.next
            pointer2 = pointer2.next
            
        return pointer1
```

全体として長くはなったが, ネストの深さとポインターの区別については改善できた.

このコードを書く際, `break` 忘れによる TLE が起きたので, `while` を使う際はループの脱出口に常に注意を払うようにしたい.
