# 問題

- 何種類かのコインが入った配列と目標となる金額が与えられる
- コインは無制限に使用可能
- 目標金額を作るために必要な最小のコイン枚数を求める

# Step1

- 5円作るとき4円から1円増やすか3円から2円増やすか…というように過去の状況をうまく使って今の状況を作る
    - DP
- 状態：dp[i]：i円作るのに必要な枚数
- 漸化式：dp[i] = min(dp[i-coin] + 1)
- 初期値：dp = float(’inf’)
    - 作れないお金は∞

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        if amount == 0:
            return 0

        coin_count = [float('inf')] * (amount + 1)
        coin_count[0] = 0

        for i in range(1, amount + 1):
            for coin in coins:
                if i - coin >= 0:
                    coin_count[i] = min(coin_count[i - coin] + 1, coin_count[i])

        if coin_count[-1] == float('inf'):
            return -1 

        return coin_count[-1]
```

※ `i-coin` の分岐を入れずに提出しインデックスエラーがでた。

配列アクセス時に範囲内におさまるか、おさまらない状況があるのか考えてから実装すべきという教訓

#### DFSでの実装

```python
class Solution:
    def coinChange(self, coins, amount):
        stack = [(0, 0)]
        INF = amount + 1
        ans = INF

        coins.sort(reverse=True)
        
        while stack:
            total, count = stack.pop()

            if count >= ans:
                continue
            
            if total == amount:
                ans = min(ans, count)
                continue
            
            for coin in coins:
                new_total = total + coin
                
                if new_total <= amount:
                    stack.append((new_total, count + 1))
        
        return ans if ans != INF else -1
```

DFSはTLEになった。

- 時間計算量： $O(coins^{amount})$

#### BFSでの実装

```python
class Solution:
    def coinChange(self, coins, amount):
        if amount == 0:
            return 0
        
        queue = deque([(0, 0)])
        visited = set([0])
        
        while queue:
            total, count = queue.popleft()
            
            for coin in coins:
                new_total = total + coin
                
                if new_total == amount:
                    return count + 1
                
                if new_total < amount and new_total not in visited:
                    visited.add(new_total)
                    queue.append((new_total, count + 1))
        
        return -1
```

以上を踏まえて修正
```
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        if amount < 0:
            return 0

        INF = amount + 1
        cnt_coin = [0] + [INF] * amount

        for i in range(1, amount + 1):
            for coin in coins:
                if i - coin >= 0:
                    cnt_coin[i] = min(cnt_coin[i - coin] + 1, cnt_coin[i])
        
        if cnt_coin[-1] == INF:
            return -1

        return cnt_coin[-1]
```
