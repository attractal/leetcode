# 問題

- 泥棒が最大何円盗めるか
- 隣り合う家のお金は盗めない
- お金は負の値をとらず家は1つ以上ある

# Step1

- 隣り合う家で大きい方をとるような貪欲法は通じず, 合計値で見る必要がある
- 動的計画法が無難では
    - 状態：今いる家までで手に入れたお金
    - 漸化式： `dp[i] = max(dp[i-1], dp[i-2]+money[i]`
    - 初期値： `dp[0]=money[0]`

```python
from typing import List

class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        rob_money = [0] * n
        rob_money[0] = nums[0]

        for i in range(1, n):
            rob_money[i] = max(rob_money[i - 1], rob_money[i - 2] + nums[i])

        return rob_money[-1]
```

# Step2

- メモ化再帰：

https://github.com/kitano-kazuki/leetcode/pull/35

再帰関数と計算結果の保存を組み合わせたもの。大きな問題を小さな問題に分割する分割統治法の一種。

トップダウン方式

```python
class Solution:
    def rob(self, nums: list[int]) -> int:

        @cache
        def rob_upto(end: int) -> int:
            if end < 0:
                return 0
            if end == 0:
                return nums[0]

            return max(rob_upto(end - 1), rob_upto(end - 2) + nums[end])

        return rob_upto(len(nums) - 1)
```
@cacheで裏でハッシュを作っている。重い計算にも耐えられるがメモリを食う。

以上を踏まえて書き直す。

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        prev2 = 0 # 二軒前までの盗んだお金
        prev1 = 0 # 一軒前までの盗んだお金
        
        for num in nums:
            current = max(prev1, prev2 + num)
            
            prev2 = prev1
            prev1 = current
            
        return prev1
```

- 変数名のつけ方に困った
- 空間計算量： $O(1)$に節約
