# Step1

- アルゴリズムの選択
    - 2Dの動的計画法
    - 状態の定義：二次元配列でそのマスに行くための行き方
    - 漸化式：grid[i][j] = grid[i-1][j]+ grid[i][j-1]
    - 初期条件：1列目すべて1,1行目すべて1

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        path_ways = [[1] * n] * m
        for row in range(1, m):
            for col in range(1, n):
                path_ways[row][col] = path_ways[row - 1][col] + path_ways[row][col - 1]
        return path_ways[m-1][n-1]
```

- 時間計算量： $O(N\times M)$
- 空間計算量： $O(N\times M)$
