# Step1

- BFS について
    - BFS：現在地から一番近い（隣の）マスをすべて確認してから、その次に近いマスを確認していく探索方法
    - **データ構造：** 先入れ先出し（FIFO）のキュー（Queue) を使って実装。
    - 再帰を使わないため、スタックオーバーフローを起こす心配なし。
- DFS について
    - DFS：とにかく行けるところまで深く進み、行き止まりになったら一つ手前に戻るという探索方法
    - **データ構造：** プログラムでは再帰関数を使って実装するのが最も簡単で一般的。
    - コードが非常にシンプルで短く書ける。
1. BFS
    - 陸地（`'1'`）を見つけたら探索スタートし、「訪問済み」に。
    - そのマスを、順番待ちの列（**キュー：Queue**）に挿入。
    - キューから1つマスを取り出し、その上下左右を確認。
    - 未訪問の陸地があれば、それらをすべて「訪問済み」にしてから、キューの最後尾に並べる。
    - キューの中身が空っぽになるまで上2つを繰り返す。空になったら、その島の探索は完了。
    
    ```python
    class Solution:
        def numIslands(self, grid: List[List[str]]) -> int:
             
            islands = 0
            rows, cols = len(grid), len(grid[0])
            visited = set()
    
            def bfs(r,c):
                continent = deque()
                visited.add((r,c))
                continent.append((r,c))
    
                while continent:
                    row, col = continent.popleft()
                    directions = [[1,0],[-1,0],[0,1],[0,-1]]
    
                    for dr, dc in directions:
                        r, c = row + dr, col + dc
    
                        if 0 <= r < rows and 0 <= c < cols and grid[r][c] == "1" and (r,c) not in visited:
                            continent.append((r,c))
                            visited.add((r,c))
    
            for r in range(rows):
                for c in range(cols):
                    if grid[r][c] == "1" and (r,c) not in visited:
                        islands += 1
                        bfs(r,c)
    
            return islands
    ```
    
    - 時間計算量： $O(M\times N)$
    - 空間計算量： $O(M\times N)$

2. DFS
    - グリッドの左上から順番に見ていき、陸地（`'1'`）を見つけたら探索スタート。
    - そのマスを訪問済みに記録。
    - 上に陸地があれば、すぐにその上の陸地へ移動。さらにその「上」に陸地があれば…と、ひたすら進む。
    - 周りがすべて水（`'0'`）または訪問済みの陸地になり、行き止まりになったら、一つ前のマスに戻って右、下、左の別のルートを試す。
    - これ以上どこにも行けなくなったら、1つの島全体の探索終了。
    
    ```python
    class Solution:
        def numIslands(self, grid: list[list[str]]) -> int:
        
            rows = len(grid)
            cols = len(grid[0])
            visited = set()
            num_islands = 0
            
            def dfs(r, c):
                if (
                    r < 0 or c < 0 or r >= rows or c >= cols or
                    grid[r][c] == '0' or (r, c) in visited
                ):
                    return
                
                visited.add((r, c))
    
                dfs(r - 1, c) # 上
                dfs(r + 1, c) # 下
                dfs(r, c - 1) # 左
                dfs(r, c + 1) # 右
    
            for r in range(rows):
                for c in range(cols):
                    if grid[r][c] == '1' and (r, c) not in visited:
                        num_islands += 1
                        dfs(r, c)
    
            return num_islands
    ```
    
    - 時間計算量： $O(M\times N)$
    - 空間計算量： 最悪 $O(M\times N)$

class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        islands = 0
        visited = set()

        rows = len(grid)
        cols = len(grid[0])

        def traverse(r,c):
            visited.add((r, c))
            frontier = deque()
            frontier.append((r, c))
            directions = [[-1, 0], [1, 0], [0, -1], [0, 1]]

            while frontier:

                row, col = frontier.popleft()
                for dr, dc in directions:
                    r, c = row + dr, col + dc
                    if (0 <= r < rows) and (0 <= c < cols) and ((r, c) not in visited) and (grid[r][c] == "1"):
                        frontier.append((r, c))
                        visited.add((r, c))

        for r in range(rows):
            for c in range(cols):
                if (grid[r][c] == "1") and ((r, c) not in visited):
                    traverse(r, c)
                    islands += 1

        return islands

            traverse(r - 1, c)
            traverse(r + 1, c)
            traverse(r, c + 1)
            traverse(r, c - 1)

                    islands += 1
