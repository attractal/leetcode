# Step1

- BFS
    - 上から順に一層ずつ足していく
    - 同じ深さでの探索順序は順不同より `list` でも `deque` でもどちらでもよさそう
    - 進む向きは一方向で重複無しなので `visited` のような変数は不要
    - 葉ノードとは右にも左にもノードがない場合なのでそこに最初に到達したら今の深さを返す

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        node_level = deque([root])
        depth = 0
        
        while node_level:
            level_size = len(node_level)
            depth += 1
            for _ in range(level_size):
                node = node_level.popleft()
                if node.left:
                    node_level.append(node.left)
                if node.right:
                    node_level.append(node.right)
                if not (node.right or node.left):
                    return depth 
```

- DFS
    - 葉ノード(root.left,root.rightが空)に到達するまでの最短距離
    - 左か右に数を数えてもらって報告をうける
    - 最小を選べばいい
    - ただ左だけないとき、右だけないときは選びようがない

```python
class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        if not root.left:
            return self.minDepth(root.right) + 1
        if not root.right:
            return self.minDepth(root.left) + 1
        
        return min(self.minDepth(root.left), self.minDepth(root.right)) + 1
```

自分の言葉にすると

**トップダウン**

- 仕事と途中経過を持って下に降りる
- ゴールで評価して、その結果を共有する

**ボトムアップ**

- 子が結果を持って上に上がってくる
- 親はそれを使って自分の結果を決める。

**4パターンを実装**

1. トップダウン＋ループ

```python
class Solution:
    def minDepth(self, root):
        if not root:
            return 0
        
        queue = deque([(root, 1)])  # (node, depth)
        
        while queue:
            node, depth = queue.popleft()

            if not node.left and not node.right:
                return depth
            
            if node.left:
                queue.append((node.left, depth + 1))
            if node.right:
                queue.append((node.right, depth + 1))
```

最短経路はBFSが早いように思う

この問題の最適解はこれだと思う

2. ボトムアップ＋再帰
- 子の結果を使って親を決める

class Solution:

            return self.minDepth(root.right) + 1
        if not root.right:

3. トップダウン＋再帰
- 深さを引き継ぐ

```python
class Solution:
    def minDepth(self, root):
        if not root:
            return 0
        
        self.ans = float('inf')
        
        def dfs(node, depth):
            if not node:
                return

            if not node.left and not node.right:
                self.ans = min(self.ans, depth)
            
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
        
        dfs(root, 1)
        return self.ans
```

4. ボトムアップ＋ループ
- 再帰ではなくスタックで
- オーバーフロー対策
```python
class Solution:
    def minDepth(self, root):
        if not root:
            return 0
        
        stack = [(root, 1)]
        min_depth = float('inf')
        
        while stack:
            node, depth = stack.pop()
            
            if not node.left and not node.right:
                min_depth = min(min_depth, depth)
            
            if node.left:
                stack.append((node.left, depth + 1))
            if node.right:
                stack.append((node.right, depth + 1))
        
        return min_depth
```
