# Step 1

- 問題：
    - 試験の点数を表す整数の配列 `nums` と、自然数 `k` が与えられ、試験の点数 `val` が1つずつ誰何されるたびに `k` 番目に高い点数を返す
- 上位 `k` 個を常にリストに持ち続け、 `val` をリストに挿入するかしないかを繰り返し、リスト内の最小値を返す
    - ソートに $O(nlogn)$、加える回数を $m$とすると $O(mnlogn)$
    - 挿入を二分探索でして $O(mn)$
        - 挿入位置を見つける(二分探索)ので $O(logn)$
        - 途中で入れて後ろすべてずらすのに $O(n)$

```python
import bisect

class KthLargest:
    def __init__(self, k: int, nums: list[int]):
        self.k = k
        self.kth_scores = sorted(nums)[-k:] 

    def add(self, val: int) -> int:
        
        if len(self.kth_scores) < self.k or val > self.kth_scores[0]:
            
            bisect.insort(self.kth_scores, val)
            
            if len(self.kth_scores) > self.k:
                self.kth_scores.pop(0)
                
        return self.kth_scores[0]
```

<summary>Heap </summary>

アルゴリズムやデータ構造の世界では、**「最大値（または最小値）を常に素早く取り出せるように、特殊なルールで並べられた木（ツリー）」**のことを指します。
「配列を毎回ソートするより賢くて速い方法」とイメージすると分かりやすいかもしれません。詳しく解説しますね。

### **1. ヒープの2つの絶対ルール**

ヒープは「完全二分木（Complete Binary Tree）」という、根元から枝分かれしていく木構造の形をとりますが、以下の2つの厳しいルールを守っています。

- **ルール1：親と子の大小関係（ヒープ条件）**
    - **最小ヒープ（Min-Heap）：** 親は必ず子よりも「小さいか等しい」。つまり、**一番上の根（ルート）が常に全体で最小**になります
    - **最大ヒープ（Max-Heap）：** 親は必ず子よりも「大きいか等しい」。つまり、**一番上の根（ルート）が常に全体で最大**になります
- **ルール2：隙間なく詰める（形状の条件）**
    - 木を作る際、必ず「上から下へ」「左から右へ」隙間なくノード（要素）を埋めていきます。途中に空席を作ってはいけません。

### **2. なぜヒープを使うのか？（メリット）**

ヒープの最大の魅力は、**「一番大きい（小さい）要素だけが知りたい。それ以外の細かい順番はどうでもいい」**という状況で、圧倒的なスピードを発揮することです。

- **最大・最小の確認が爆速：** 一番上を見るだけなので、計算量は $O(1)$ です。
- **追加・削除が速い：** 新しいデータを入れたり、一番上を取り除いたりした後、木を再編成する（ヒープ条件を満たすように入れ替える）操作が必要ですが、木の高さ分だけ動かせば済むため、計算量は $O(\log N)$ で済みます。（Nは要素数）
もし普通の配列で毎回並び替え（ソート）をすると $O(N \log N)$ かかってしまうので、次々とデータが来るような状況（ストリーム処理）ではヒープの圧勝です。

### **3. 実は中身は「ただの配列」**

図で描くと木構造（ツリー）ですが、実はプログラム上で実装する際は、ポインタ（矢印）を使った複雑な構造ではなく、**ただの1次元配列**として保存されます。
ルール2の「隙間なく詰める」性質のおかげで、配列のインデックス（番号）を計算するだけで、簡単に親や子を見つけることができるからです。

- ある要素がインデックス $i$ にあるとき:
    - 左の子は $2i + 1$
    - 右の子は $2i + 2$
    - 親は $(i - 1) // 2$

このように、メモリの無駄遣いがなく、データへのアクセスも非常に効率的です。

- サイズ k の最小ヒープを使えばよさそう
- 初期化：
    - 空の最小ヒープを用意
    - 与えられた配列 `nums` の要素を1つずつヒープに追加
    - ヒープのサイズが k を超えるたびに、最小要素を削除
    - 上位 k 個の要素だけがヒープに残り続ける
- 要素追加：
    - 新しい要素 `val` をヒープに追加する
    - ヒープのサイズが k を超えたら、最小要素をポップする
    - ヒープの先頭要素を返す

```python
class KthLargest:

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.kth_scores = []

        for num in nums:
            self.add(num)

    def add(self, val: int) -> int:
        heapq.heappush(self.kth_scores,val)

        if len(self.kth_scores) > self.k:
            heapq.heappop(self.kth_scores)

        return self.kth_scores[0]
```

- 時間計算量： $O(N\log k)$
- 空間計算量： $O(k)$
