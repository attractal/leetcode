# Step1

ポインタ `node` を作成し, 連結リストを前から見ていく.

 `node.val` が同じ場合はつなぎ方を変え, 異なる場合はポインタを更新する.

新しい空の `ListNode` を作成しようと考えたが, python の代入は参照なので, そのまま `head` を返せばよいことに気づいた.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        while node is not None and node.next is not None:
            if node.val == node.next.val:
                node.next = node.next.next
            else:
                node = node.next
        return head
```

- 時間計算量：O(n)
- 空間計算量：O(1)

    ```python
    # Definition for singly-linked list.
    # class ListNode:
    #     def __init__(self, val=0, next=None):
    #         self.val = val
    #         self.next = next
    class Solution:
        def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
            if not head:
                return None
            
            dummy = ListNode(0)
            new_curr = dummy
            
            old_curr = head
            
            while old_curr is not None:
                if new_curr is dummy or old_curr.val != new_curr.val:
                    new_curr.next = ListNode(old_curr.val)
                    new_curr = new_curr.next
                
                old_curr = old_curr.next
                
            return dummy.next
    ```
    
    - Step3 で再帰を用いたコードを作成されていた
        - 非破壊的な再帰
    
    ```python
    class Solution:
        def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
            # ベースケース：末尾に達したらNoneを返す
            if not head:
                return None
            
            # 再帰の呼び出し：次のノード以降の「重複除去済みリスト」を取得
            next_list = self.deleteDuplicates(head.next)
            
            # 判定：現在の値が、次のリストの先頭と同じか？
            if next_list and head.val == next_list.val:
                # 同じなら、自分は含めず、次のリストをそのまま返す
                return next_list
            else:
                # 違うなら、自分のコピーを作って、そこに次のリストを繋げる
                new_node = ListNode(head.val)
                new_node.next = next_list
                return new_node
    ```
    

- 破壊的な再帰
```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        
        head.next = self.deleteDuplicates(head.next)
        
        if head.val == head.next.val:
            return head.next
        
        return head
```
