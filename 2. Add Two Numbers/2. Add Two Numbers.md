# Step1

両者リストを前から順にたしていく。ひっ算をイメージする。10を超えなければ2つの和がリストの数値となるが、繰り上がりが発生する場合は、10で割ったあまりをリストの数値とし、10で割った商を繰り上がりとする。

同様の走査をどちらのリストもなくなり、繰り上がりがなくなるまで繰り返す。

新たなノードを作成し格納するので `dummy` を作成する。

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        
        dummy = ListNode()
        ans = dummy

        carry = 0
        total = 0

        while l1 is not None or l2 is not None or carry:
            total = carry

            if l1 is not None:
                total += l1.val
                l1 = l1.next
            
            if l2 is not None:
                total += l2.val
                l2 = l2.next

            num = total % 10
            carry = total // 10
            dummy.next = ListNode(num)
            dummy = dummy.next
        
        return ans.next
```

- 時間計算量：O(n)
- 空間計算量：O(n)

# Step2

- 再帰を用いた手法

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode], carry: int = 0) -> Optional[ListNode]:
        if not l1 and not l2 and carry == 0:
            return None

        val1 = l1.val if l1 else 0
        val2 = l2.val if l2 else 0

        total = val1 + val2 + carry
        carry = total // 10

        current_node = ListNode(total % 10)

        next_l1 = l1.next if l1 else None
        next_l2 = l2.next if l2 else None
        
        current_node.next = self.addTwoNumbers(next_l1, next_l2, carry)
        
        return current_node
```

- 時間計算量：O(n)
- 空間計算量：O(1)
- 再帰の方がきれいに書けた
    - ノードの上から足していくという操作は変わらないから
- 番兵の有無
    - 再帰では不要
        - 関数自体が完成したリストの最初の文字を返し、それを `head` にするリストを作成するため
        - 新しいノードを作り、その `next` に再帰の戻り値（未来の結果）を代入するため
        - 後ろからさかのぼっていくので関数の最初の呼び出しの戻り値が `head` になる
            - 呼び出しで `head` を固定するイメージ？
    - 反復では必要
        - ループ内でリストを構築する際、先頭を固定しておくため
        
- 反復を番兵なしで
    - `head` ：先頭を指すための固定ポインタ
    - `tail` ：更新し続ける作業ポインタ

```python
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        head = None  # 最終的に返すリストの先頭
        tail = None  # 現在構築中のリストの末尾
        carry = 0
        
        while l1 is not None or l2 is not None or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            
            total = val1 + val2 + carry
            carry = total // 10
            new_node = ListNode(total % 10)
            
            if not head:
                # 最初の1回目だけ実行：headを固定する
                head = new_node
                tail = new_node
            else:
                # 2回目以降：tailの次に繋いで、tailを移動させる
                tail.next = new_node
                tail = tail.next
            
            if l1 is not None: l1 = l1.next
            if l2 is not None: l2 = l2.next
            
        return head
```
