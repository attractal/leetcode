# 問題

- `nums` に重複整数列が入っている
- 個数の大きい順に k 個取り出し順不同に並べたリストを返す

# Step 1

- 数値を `key` 、出現回数を `value` とする辞書を作成
    - `Counter()` のようなもの
    - 今回は `get()` で実装
- `value` を軸に並びかえ、上位 `k` 個を返す

```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_nums = {}
        for num in nums:
            count_nums[num] = count_nums.get(num, 0) + 1
        return sorted(count_nums, key=lambda x: count_nums[x], reverse=True)[:k]
```

# Step 2

- Step 1　のコードを書き換えるなら `Counter()` を使うとか
- `most_common(k)` という便利なメソッドがある
    - https://docs.python.org/3/library/collections.html#collections.Counter
    - 勝手に回数でソートして、 タプルで返してくれる

```python
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_nums = Counter(nums)
        return [x[0] for x in count_nums.most_common(k)]
```

- ソートを heap を用いて実装すると

```python
import heapq
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_nums = Counter(nums)
        
        kth_count_num = []
        
        for num, freq in count_nums.items():

            heapq.heappush(kth_count_num, (freq, num))

            if len(kth_count_num) > k:
                heapq.heappop(kth_count_num)
                
        return [num for freq, num in kth_count_num]
```

- 時間計算量： $O(N\log k)$
    - カウントに $O(N)$
    - ヒープへの操作に $O(N\log k)$
- 空間計算量： $O(N)$
- 実装時、 `kth_count_num` に `(freq, num)` のタプルが入ることを失念し、 `return [ num  for num in kth_count_num]` としていた
    - `Counter` 自体は dict-like で、ここではヒープ `kth_count_num` がタプル `(freq, num)` を保持している
- さらに、Gemini曰くより短く書けるそう

```python
import heapq
from typing import List
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count_nums = Counter(nums)
        # count_numsのキーを、count_nums.get(値) を基準にして上位k個取得する
        return heapq.nlargest(k, count_nums.keys(), key=count_nums.get)
```

     <summary>   Quick Select</summary> 
        
        #### **1. なぜ「ソート」より速いのか？**
        
        要素を探すとき、最も単純な方法は「配列全体をソートして $k$ 番目を取り出す」ことですが、これには $O(N \log N)$ の時間がかかります。
        Quickselect の賢いところは、**「全体を綺麗に並べ替える必要はない。探したい** $k$ **番目が含まれている半分だけを整理すればいい」** と割り切っている点です。
        
        - **クイックソート**: ピボット（基準値）を決めて「小さい組」と「大きい組」に分けたら、**両方の組**をさらにソートしに行きます。
        - **Quickselect**: ピボットで分けた後、探している $k$ 番目が「小さい組」にあると分かれば、**「大きい組」は完全に無視（切り捨て）** して、「小さい組」の中だけで探索を続けます。
        
        探索範囲が $N \to N/2 \to N/4 \dots$ と半分ずつ減っていくため、足し合わせると全体の処理回数は $2N$ 程度に収まり、**平均計算量が** $O(N)$ になります。
        
        #### **2. アルゴリズムの具体的なステップ**
        
        例として「 $k$ 番目に**小さい**要素」を探す手順を説明します。
        1. **ピボットの選択**: 配列の中からランダムに1つ、基準となる要素（ピボット）を選びます。
        2. **パーティション（分割）**:
            ◦ 配列を操作し、ピボットより「小さい要素」を左側に、「大きい要素」を右側に集めます。
            ◦ 最後にピボット自身を、左と右の境界線に置きます。
            ◦ この時点で、**「ピボットが配列全体の中で何番目に小さいか（インデックス）」が完全に確定**します。
        3. **条件分岐（ここが Quickselect のキモ）**:
            ◦ ピボットのインデックスが、ちょうど探している $k$ と同じ $\to$ **発見！ピボットを返して終了。**
            ◦ ピボットのインデックスが $k$ より大きい $\to$ 探している要素は**左側のグループ**にあるので、左側だけでステップ1からやり直す。
            ◦ ピボットのインデックスが $k$ より小さい $\to$ 探している要素は**右側のグループ**にあるので、右側だけでステップ1からやり直す。

- 実装
        
```python
import random
from collections import Counter
from typing import List

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        # 1. 各数字の出現回数をカウント
        count_nums = Counter(nums)
        unique = list(count_nums.keys())
        
        # パーティション（分割）処理
        def partition(left: int, right: int, pivot_index: int) -> int:
            pivot_freq = count_nums[unique[pivot_index]]
            
            # ピボットを一旦、配列の右端に退避させる
            unique[pivot_index], unique[right] = unique[right], unique[pivot_index]
            
            store_index = left
            # 左端から探索し、ピボットより頻度が「大きい」ものを左に詰めていく
            for i in range(left, right):
                if count_nums[unique[i]] > pivot_freq:
                    unique[store_index], unique[i] = unique[i], unique[store_index]
                    store_index += 1
            
            # 退避させていたピボットを、境界線（store_index）の位置に戻す
            unique[right], unique[store_index] = unique[store_index], unique[right]
            
            # ピボットの最終的なインデックスを返す
            return store_index
            
        # Quick Select の本体
        def quickselect(left: int, right: int, k_target: int):
            if left == right:
                return
            
            # 偏りを防ぐため、ランダムにピボットを選ぶ（重要）
            pivot_index = random.randint(left, right)
            
            # 配列を分割し、ピボットの確定位置を取得
            pivot_index = partition(left, right, pivot_index)
            
            # ピボットの位置がちょうど k に等しければ、左側に上位 k 個が集まっている状態
            if k_target == pivot_index:
                return
            # k より小さければ、目的の要素は右側にある
            elif k_target > pivot_index:
                quickselect(pivot_index + 1, right, k_target)
            # k より大きければ、目的の要素は左側にある
            else:
                quickselect(left, pivot_index - 1, k_target)
                
        # 実行開始（配列のインデックス0 〜 末尾の範囲で、上位 k 個を集める）
        n = len(unique)
        # k は「個数」なので、0-index のターゲットは k-1 とする
        quickselect(0, n - 1, k - 1)
        
        # 先頭から k 個を返す（この k 個の中身はソートされていないが、上位 k 個であることは保証される）
        return unique[:k]
 ```

    if k is None:

    return sorted_items[:k]

```python
import heapq

def my_most_common_heap(count_dict: dict, k: int) -> list:
    heap = []
    
    for key, count in count_dict.items():
        heapq.heappush(heap, (count, key))
      
        if len(heap) > k:
            heapq.heappop(heap)
            
    result = []
    while heap:
        count, key = heapq.heappop(heap)
        result.append((key, count))

    return result[::-1]]
```            
          
            
- 時間計算量： $O(N\log k)$
