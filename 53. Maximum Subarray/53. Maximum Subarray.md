# 問題

- 配列の部分和の最大値を求める

# Step1

- **DP**
    - **状態の定義：**
        - cumulated (本来の dp[i]): $i$ 番目の要素を末尾とする連続部分配列の最大和
        - largest_sum: これまでに計算したすべての cumulated の中での最大値
    - **漸化式の導出：**
        - 負なら0にリセット、それ以外ならメモ
        - 最大値も同時に更新
    - **初期条件の決定：**
        - **`largest_sum = -float("inf")`**: どんな和よりも小さい値から始めることで、最初の要素が負数であっても正しく更新
    
    ※ 1回目の提出で最大値の初期値を0にしてしまった。
    

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        largest_sum = -float("inf")
        cumulated = 0

        for num in nums:
            cumulated += num
            largest_sum = max(largest_sum, cumulated)
            if cumulated < 0:
                cumulated = 0
        
        return largest_sum
```

- 時間計算量： $O(N)$
- 空間計算量： $O(1)$

## Follow upの分割統治法

- 配列を中央のインデックスで 左半分 と 右半分 に分割
1. 左半分に完全に収まっている
2. 右半分に完全に収まっている
3. 中央をまたいでいる

の3通り

1と2は再帰的に計算できる。

3番目は、中央から左に向かって連続する最大値と、中央から右に向かって連続する最大値を別々に計算し、それを足し合わせる。

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        def findBestSubarray(left: int, right: int) -> int:
            if left == right:
                return nums[left]
            
            mid = (left + right) // 2
            
            left_max = findBestSubarray(left, mid)
          
            right_max = findBestSubarray(mid + 1, right)
            
            cross_left_sum = 0
            cross_left_max = float('-inf')
            for i in range(mid, left - 1, -1):
                cross_left_sum += nums[i]
                cross_left_max = max(cross_left_max, cross_left_sum)
                
            cross_right_sum = 0
            cross_right_max = float('-inf')
            for i in range(mid + 1, right + 1):
                cross_right_sum += nums[i]
                cross_right_max = max(cross_right_max, cross_right_sum)
                
            cross_max = cross_left_max + cross_right_max
            
            return max(left_max, right_max, cross_max)
            
        return findBestSubarray(0, len(nums) - 1)
```

- 時間計算量： $O(N \log N)$
- 空間計算量： $O(\log N)$
