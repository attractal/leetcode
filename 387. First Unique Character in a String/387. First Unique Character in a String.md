# 問題

- 文字列
- 出現回数が1回の文字の中で最初に出てくる文字のインデックスを返す
- なければ-1
- 制約
    - 文字列の長さは1以上
    - 文字は小文字のみ

# Step 1

- アルゴリズムの選択
    - Hash で出現回数をメモ
    - value が1の最初の文字とそのインデックスを返せばよい
    - 制約から小文字のみなので一致かどうかは `==` で確認するだけでいい

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        char_to_count = {}

        for word in s:
            char_to_count[word] = char_to_count.get(word, 0) + 1

        for index, word in enumerate(s):
            if char_to_count[word] == 1:
                return index
        
        return -1
```

- 時間計算量： $O(N)$
- 空間計算量： $O(N)$

    - char_to_countを走査
```python
from collections import Counter

class Solution:
    def firstUniqChar(self, s: str) -> int:
        char_to_count = Counter(s)
        
        for char, count in char_to_count.items():
            if count == 1:
                return s.index(char)
                
        return -1
```
