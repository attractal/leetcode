# Step1

2つポインタを用意する

ひとつは被りを探すポインタ `node` 、もう一方はかぶりが生じる前のポインタ `previous` である。

かぶりが生じた場合はかぶりの最終地点まで走査し、その次のノードを `previous` からつなげばよく、かぶりがない場合は `previous` , `node` を更新すればよい。

Example2のようにはじめからかぶっているケースに対応するために、先頭の前にダミーノードを 1 つ追加してからリストを走査する。

ダミーノードの値自体は比較などに使っておらず任意でよい。

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        previous = dummy
        node = head
        
        while node is not None:
            if node.next is not None and node.val == node.next.val:
                while node.next is not None and node.val == node.next.val:
                    node = node.next
                previous.next = node.next
            else:
                previous = previous.next

            node = node.next
            
        return dummy.next
```

- 時間計算量：O(n)
- 空間計算量：O(1)

```python
while node is not none:
    if node.next is not None or node.val != node.next.val:
        previous = node
        node = node.next
        continue
        
    # 重複を発見、一括処理モードに入る
```

`dummy` を使わずにかくと、 `previous` の判定が必要となり、

```python
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # --- 前半：新しい head を見つける ---
        while head and head.next is not None and head.val == head.next.val:
            while head.next and head.val == head.next.val:
                head = head.next
            head = head.next
        
        # --- 後半：中間のノードを処理する ---
        node = head
        previous = None # dummyがないので、最初はNoneでスタートせざるを得ない
        
        while node is not None:
            is_duplicate = False
            # 重複があるかチェック
            while node.next is not None and node.val == node.next.val:
                is_duplicate = True
                node = node.next
            
            if is_duplicate:
                # 重複があった場合、prevの次を「重複の次」に飛ばす
                # prevがNone（先頭付近）かどうかのチェックが毎回必要
                if previous is not None:
                    previous.next = node.next
                # nodeを次に進める
                node = node.next
            else:
                # 重複がなければ、prevを更新して次に進む
                previous = node
                node = node.next
        
        return head
```
